# Upgrading to kvn-tui v0.22.0 on Omarchy

[Back to upgrading guide](../upgrading.md)

Version 0.22.0 adds native Omarchy 4 integration while retaining the Omarchy 3
Waybar setup. VPN profiles and connection settings do not require migration.

## Upgrade and reinstall the desktop integration

1. Upgrade kvn-tui through your usual package source.

2. Confirm that the new version is installed:

   ```bash
   kvn-tui --version
   ```

   The command should report `kvn-tui 0.22.0` or newer.

3. Re-run the Omarchy setup as your regular user, without `sudo`:

   ```bash
   kvn-tui setup --omarchy
   ```

   The installer detects the installed Omarchy major version automatically.
   On Omarchy 4 it adds a command module to `~/.config/omarchy/shell.json`, a
   Lua window rule, and the focus-aware launcher. On Omarchy 3 it continues to
   configure the existing Waybar and Hyprland `.conf` files.

4. When prompted for a shortcut, press Enter to accept `Super + Ctrl + K`, or
   enter a custom combination such as:

   ```text
   SUPER SHIFT, V
   ```

   On Omarchy 4, the default `Super + Ctrl + K` shortcut belongs to Herdr.
   Choosing it explicitly unbinds Herdr before assigning kvn-tui. Custom
   shortcuts are also unbound first to prevent duplicate Hyprland bindings.

## Verify Omarchy 4

The Shell configuration hot-reloads after setup. The right side of the bar
should contain the VPN icon immediately before Bluetooth:

```text
󰦜  Bluetooth  Network  Audio
```

The disconnected icon is `󰦜`; when connected it changes to `󰦝`. Hovering shows
the connection state and active profile, and clicking the icon opens or focuses
the TUI.

Confirm that the Shell module was installed:

```bash
jq '.bar.layout.right[] | select((.id // .) == "kvn-tui")' \
  ~/.config/omarchy/shell.json
```

Confirm that Hyprland accepted the generated Lua configuration:

```bash
hyprctl reload
hyprctl configerrors
```

`hyprctl configerrors` should produce no output. The installer automatically
rolls back its Omarchy 4 configuration changes if a reload introduces a new
Hyprland error.

Finally, check that kvn-tui detects the active Omarchy theme:

```bash
kvn-tui doctor
```

The report should include a line similar to:

```text
✓ Omarchy detected; active theme: tokyo-night
```

## Theme migration

Omarchy 4 stores its active theme under
`$XDG_STATE_HOME/omarchy/current/theme.name`; Omarchy 3 used the XDG config
directory. kvn-tui v0.22.0 checks the new location first and falls back to the
old one, so no symlink or manual path migration is needed.

To follow Omarchy theme changes automatically, open the theme picker with `C`
and select `Auto (Omarchy)`. An explicitly selected palette remains pinned.
Version 0.22.0 bundles all 22 stock Omarchy 4 palettes, including Last Horizon,
Lupine, and Solitude.

## Backups

The setup command creates one-time backups with the suffix
`.bak.before-kvn-tui`. Keep them until the bar icon, launcher, shortcut, and
window rule have been verified. Afterwards, only the backup files can be
removed with:

```bash
kvn-tui clean --omarchy
```

This cleanup command does not remove the active integration.
