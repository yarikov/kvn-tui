# Upgrading to kvn-tui v0.27.0 on Omarchy 4

[Back to upgrading guide](../upgrading.md)

Version 0.27.0 moves the Omarchy 4 bar widget into the standalone
[`yarikov.omakvn`](https://github.com/yarikov/omakvn) plugin. Upgrading the
kvn-tui package does not update the existing desktop integration by itself.
VPN profiles and connection settings do not require migration.

## Install the plugin after upgrading

1. Upgrade kvn-tui through your usual package source.

2. Confirm that version 0.27.0 or newer is installed:

   ```bash
   kvn-tui --version
   ```

3. Re-run the Omarchy setup as your regular user, without `sudo`:

   ```bash
   kvn-tui setup --omarchy
   ```

   Internet access is required for the first installation because setup clones
   the plugin from GitHub. The installer automatically migrates the previous
   embedded `kvn.tui` or `yarikov.omakvn` widget, replaces the legacy
   `kvn-tui` command module in `~/.config/omarchy/shell.json`, and preserves the
   existing launcher, keybinding, and window rule.

4. Check that Omarchy recognizes the plugin:

   ```bash
   omarchy plugin list
   omarchy plugin validate ~/.config/omarchy/plugins/yarikov.omakvn
   ```

   The plugin directory should be a Git checkout and the Shell configuration
   should contain the new plugin ID:

   ```bash
   test -d ~/.config/omarchy/plugins/yarikov.omakvn/.git
   jq '.bar.layout.right[] | select((.id // .) == "yarikov.omakvn")' \
     ~/.config/omarchy/shell.json
   ```

The installer asks a running Omarchy Shell to rescan its plugins, so the VPN
widget should normally appear immediately. If it does not, log out and back in
once. The widget should then show the current VPN state; clicking it opens or
focuses kvn-tui.

## Troubleshooting

If setup reports that this Omarchy build lacks the Shell plugin registry,
update Omarchy and run `kvn-tui setup --omarchy` again. Until then, setup keeps
the legacy command-based bar module as a fallback.

If the first plugin download fails, restore network access and repeat the setup
command. The migration is idempotent, and a failed download does not delete an
existing embedded plugin.

If setup refuses to update `yarikov.omakvn` because the directory is managed by
a different Git repository, inspect
`~/.config/omarchy/plugins/yarikov.omakvn` and its `origin` before removing or
renaming it. The installer deliberately does not overwrite an unrecognized
checkout.
